# Acordos de Qualidade da Equipe

## Definition of Ready (DoR)

Uma Issue só pode ser assumida por alguém quando:

- [ ] Tem um título que informa o que será entregue
- [ ] Tem pelo menos 2 critérios de aceitação verificáveis
- [ ] Tem a label `user-story` ou `enhancement`
- [ ] Indica o épico pai (ex.: Parte do Épico #12)

Se for uma história de usuário (`user-story`):

- [ ] Está escrita no formato Como / Quero / Para que
- [ ] Usa o nome de uma persona de `docs/PERSONAS.md`

Se envolver receitas:

- [ ] Informa a categoria (ex.: doce, salgado, bebida)

## Definition of Done (DoD)

Uma entrega só está concluída quando:

- [ ] Os critérios de aceitação da Issue foram atendidos
- [ ] As receitas novas ou alteradas seguem o template do repositório
- [ ] Os links novos ou alterados foram testados e funcionam
- [ ] A ortografia do texto foi revisada e os erros encontrados foram corrigidos
- [ ] O Pull Request tem 3 aprovações
- [ ] O merge na main foi feito sem conflitos pendentes
