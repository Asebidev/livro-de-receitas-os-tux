# Livro de Receitas – Os Tux

Bem-vindo ao **Livro de Receitas Colaborativo – Os Tux**!

Este projeto foi desenvolvido como atividade prática da disciplina de Gerência de Configuração de Software, utilizando Git e GitHub. Nosso objetivo é reunir receitas em um livro digital organizado por categorias, praticando o trabalho colaborativo, o controle de versões e a revisão de código.

## Estrutura do projeto

O livro está organizado nas seguintes categorias:

- [Saladas](saladas/)
- [Carnes](carnes/)
- [Sopas](sopas/)
- [Massas](massas/)
- [Sobremesas](sobremesas/)

O arquivo [menu.md](menu.md) funciona como menu principal para navegar pelas receitas.

## Como contribuir

1. Escolha uma receita e abra uma Issue descrevendo sua contribuição.
2. Crie uma branch seguindo o padrão `feature/<categoria>-<nome-da-receita>`.
3. Adicione a receita na pasta correspondente.
4. Atualize o arquivo `menu.md` com o link da nova receita.
5. Faça commits seguindo o padrão Conventional Commits, utilizando prefixos como `feat:` e `docs:`.
6. Envie sua branch ao GitHub e abra um Pull Request para a branch `main`.
7. Aguarde pelo menos 3 aprovações de revisores diferentes antes do merge.

Para conhecer todas as regras de contribuição, consulte o arquivo [CONTRIBUTING.md](CONTRIBUTING.md).
